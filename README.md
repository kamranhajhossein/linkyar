# لینک‌یار — دستیار لینک‌سازی داخلی برای وردپرس

[![CI](https://github.com/kamranhajhossein/linkyar/actions/workflows/ci.yml/badge.svg)](https://github.com/kamranhajhossein/linkyar/actions/workflows/ci.yml)

لینک داخلی یکی از ارزان‌ترین و مؤثرترین کارهای سئو است، ولی کسی حوصله‌اش را ندارد. باید یادتان باشد کدام مطلب قبلاً نوشته شده، نشانی‌اش را پیدا کنید و جای مناسبش را در متن بگذارید. نتیجه این می‌شود که نیمی از صفحه‌های سایت **یتیم** می‌مانند و هیچ صفحه‌ای به آن‌ها لینک نمی‌دهد.

لینک‌یار این کار را خودکار می‌کند. همین‌طور که مطلب می‌نویسید، عبارت‌هایی از متن را که می‌شود به مطالب، برگه‌ها و محصولات دیگر سایت لینک داد پیدا می‌کند. شما فقط روی «لینک بده» می‌زنید.

<a id="how"></a>
## چطور کار می‌کند

۱. لینک‌یار از همهٔ محتوای منتشرشدهٔ سایت یک نمایه می‌سازد: نشانی هر صفحه و عبارت‌هایی که باید به آن لینک شوند.
۲. در ویرایشگر، متن شما را با این عبارت‌ها مقایسه می‌کند و بهترین جاها را پیشنهاد می‌دهد. صفحه‌های یتیم و کم‌لینک اولویت بالاتری می‌گیرند.
۳. با «لینک بده»، همان عبارت در همان پاراگراف لینک می‌شود و بلوک انتخاب می‌شود تا ببینید چه شد.
۴. با هر ذخیره، نقشهٔ لینک‌های داخلی به‌روز می‌شود و گزارش یتیم‌ها همیشه تازه است.

### چرا «فارسی‌فهم» مهم است؟

ابزارهای خارجی لینک‌سازی، «سئوي فني» را با «سئوی فنی» یکی نمی‌دانند و نیم‌فاصله، اِعراب و «ۀ» را هم نمی‌فهمند. لینک‌یار قبل از مقایسه متن را یکسان می‌کند. پس همهٔ این‌ها یک عبارت حساب می‌شوند:

| در متن شما | عبارت مطلب مقصد |
|---|---|
| `سئوي فني` | `سئوی فنی` |
| `عطر مردانهٔ` | `عطر مردانه` |
| `کتاب‌های جدید` | `کتاب های جدید` |
| `مُحَمَّد` | `محمد` |
| `سال ۱۴۰۵` | `سال 1405` |

<a id="features"></a>
## امکانات

- **نوار کناری ویرایشگر بلوکی:** پیشنهادها با متن اطرافشان، برچسب «یتیم» یا تعداد لینک ورودی مقصد، و درج لینک با یک کلیک.
- **ویرایشگر کلاسیک و محصولات ووکامرس:** یک متاباکس با همان پیشنهادها و دکمهٔ کپی لینک.
- **جلوگیری از لینک تکراری و بد:** به خود مطلب لینک نمی‌دهد. مقصدی که قبلاً در متن لینک شده دوباره پیشنهاد نمی‌شود. داخل لینک‌ها و تیترها چیزی پیشنهاد نمی‌دهد. پیشنهادها روی هم نمی‌افتند و هر پاراگراف حداکثر ۲ پیشنهاد می‌گیرد.
- **گزارش لینک‌ها در «ابزارها ← لینک‌یار»:** صفحه‌های یتیم، کم‌لینک، پرلینک و بدون عبارت، با تعداد لینک ورودی و خروجی و فیلتر بر اساس نوع محتوا.
- **WP-CLI:** دستورهای `wp linkyar rebuild`، `wp linkyar orphans --format=csv` و `wp linkyar suggest <id>`.
- **سبک و سریع:** یک جدول کوچک دوستونی برای نقشهٔ لینک‌ها دارد. سمت سایت هیچ اسکریپتی بارگذاری نمی‌کند و تأثیری روی سرعت سایت ندارد.
- **ترجمهٔ کامل فارسی.**

<a id="install"></a>
## نصب

۱. فایل `linkyar.zip` را از [آخرین نسخه](https://github.com/kamranhajhossein/linkyar/releases/latest) دانلود کنید.
۲. پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری افزونه، و فعال کنید.
۳. به **ابزارها ← لینک‌یار** بروید و «ساخت نقشهٔ لینک‌ها» را بزنید. برای بیشتر سایت‌ها چند ثانیه طول می‌کشد و فقط یک بار لازم است.
۴. یک مطلب را باز کنید و از نوار بالای ویرایشگر، آیکون لینک (🔗 لینک‌یار) را بزنید.

<a id="phrases"></a>
## عبارت‌ها از کجا می‌آیند

لینک‌یار برای هر صفحه این عبارت‌ها را جمع می‌کند و پیشنهادها را به همین ترتیب اولویت می‌دهد:

| منبع | توضیح |
|---|---|
| **عبارت‌های شما** | در نوار کناری یا متاباکس هر مطلب، بخش «عبارت‌هایی که باید به این مطلب لینک شوند». با ویرگول فارسی یا انگلیسی جدا کنید. |
| **کلمهٔ کلیدی کانونی** | خودکار از Yoast SEO و Rank Math خوانده می‌شود. Rank Math چند کلمهٔ کلیدی را پشتیبانی می‌کند و همه‌شان استفاده می‌شوند. |
| **عنوان** | عنوان کامل، اگر بین ۲ تا ۸ کلمه باشد، و بخش اول عنوان‌هایی مثل «بهترین عطر مردانه ۲۰۲۶ \| راهنمای خرید». |

عنوان‌های تک‌کلمه‌ای عمداً نادیده گرفته می‌شوند، چون کلمه‌ای مثل «عطر» یا «درباره» در هر متنی پیدا می‌شود و لینک بی‌ربط می‌سازد. اگر برای این صفحه‌ها لینک می‌خواهید، یک عبارت دستی برایشان تعریف کنید. تب «بدون عبارت» در گزارش این صفحه‌ها را نشانتان می‌دهد.

<a id="report"></a>
## گزارش یتیم‌ها

در **ابزارها ← لینک‌یار** این‌ها را می‌بینید:

- تعداد صفحه‌های نمایه‌شده، کل لینک‌های داخلی، تعداد صفحه‌های یتیم و میانگین لینک ورودی.
- تب‌های **یتیم‌ها** (۰ ورودی)، **ضعیف** (۱ تا ۲)، **پرلینک‌ترین‌ها**، **بدون عبارت** و **همه**.
- برای هر صفحه: لینک ویرایش، تعداد ورودی و خروجی، و عبارت‌هایی که به آن لینک می‌شوند.

یک روش کاری خوب: صفحهٔ یتیم را پیدا کنید، عبارتش را ببینید، یک مطلب مرتبط را باز کنید و «پیدا کردن فرصت‌های لینک» را بزنید. یتیم‌ها همیشه بالای فهرست پیشنهادها هستند.

خروجی برای اکسل:

</div>

```bash
wp linkyar orphans --post_type=product --format=csv > orphans.csv
```

<a id="faq"></a>
## سؤالات متداول

<details>
<summary><b>خودش بدون اجازه لینک اضافه می‌کند؟</b></summary>

نه. لینک‌یار فقط پیشنهاد می‌دهد و تا شما «لینک بده» را نزنید هیچ چیزی در متن عوض نمی‌شود. لینک‌سازی خودکار و انبوه برای سئو خطرناک است و عمداً پیاده نشده.
</details>

<details>
<summary><b>با المنتور یا صفحه‌سازها کار می‌کند؟</b></summary>

نوار کناری فقط در ویرایشگر بلوکی و متاباکس فقط در ویرایشگر کلاسیک ظاهر می‌شود. نقشهٔ لینک‌ها و گزارش یتیم‌ها از `post_content` خوانده می‌شوند. المنتور نسخهٔ HTML صفحه را هم آنجا ذخیره می‌کند، پس لینک‌های صفحه‌های المنتوری معمولاً در گزارش حساب می‌شوند.
</details>

<details>
<summary><b>روی سایت با هزاران مطلب کند نمی‌شود؟</b></summary>

نمایه یک بار ساخته و ذخیره می‌شود و با هر ذخیرهٔ مطلب فقط همان یک مورد به‌روز می‌شود. ساخت نقشه ۱۰۰ تایی در پیشخوان و ۲۰۰ تایی در WP-CLI جلو می‌رود. پیشنهاددهی فقط وقتی اجرا می‌شود که در ویرایشگر دکمه را بزنید.
</details>

<details>
<summary><b>لینک‌های قدیمی که با «ي» عربی یا نشانی کامل دامنه نوشته شده‌اند شناخته می‌شوند؟</b></summary>

بله. نشانی‌های مطلق، نسبی، با یا بدون www، کدگذاری‌شده یا نشده، و `?p=` و `?page_id=` همه به شناسهٔ صفحه تبدیل می‌شوند. لینک به دامنه‌های دیگر نادیده گرفته می‌شود.
</details>

<details>
<summary><b>اگر پلاگین را حذف کنم چه می‌شود؟</b></summary>

لینک‌هایی که درج کرده‌اید لینک معمولی HTML هستند و سر جایشان می‌مانند. جدول نقشهٔ لینک‌ها، تنظیمات و عبارت‌های دستی با حذف پلاگین پاک می‌شوند.
</details>

## برای توسعه‌دهندگان

| فیلتر | کاربرد |
|---|---|
| `linkyar_post_types` | نوع‌های محتوایی که نمایه می‌شوند و لینک می‌گیرند |
| `linkyar_phrases` | افزودن یا حذف عبارت‌های یک صفحه (مثلاً از یک فیلد ACF) |
| `linkyar_max_links_per_block` | حداکثر پیشنهاد در هر پاراگراف (پیش‌فرض ۲) |

</div>

```php
// Example: also use an ACF field as link phrases.
add_filter( 'linkyar_phrases', function ( $phrases, $post ) {
	$extra = get_field( 'seo_synonyms', $post->ID );
	foreach ( array_filter( array_map( 'trim', explode( ',', (string) $extra ) ) ) as $kw ) {
		$phrases[ Linkyar_Text::fold( $kw ) ] = 'custom';
	}
	return $phrases;
}, 10, 2 );
```

## English

**Linkyar** is an internal-linking assistant for WordPress with first-class Persian support.

- **Editor sidebar** (block editor) suggests where your text can link to other posts, pages and products, with context and the target's inbound-link count; one click inserts the link.
- **Classic editor / WooCommerce** metabox with the same suggestions.
- **Persian-aware matching**: ي/ی, ك/ک, ZWNJ, diacritics, ۀ and Persian digits are folded before comparing.
- **Phrases** come from your own per-post phrases, Yoast / Rank Math focus keywords and titles.
- **Orphan report** under *Tools → Linkyar* and `wp linkyar orphans`, backed by a small link-graph table that updates on every save.
- Never edits content on its own. Requires WordPress 6.2+ and PHP 7.4+. Persian (fa_IR) translation included.

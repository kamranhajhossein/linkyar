Finds internal-link opportunities while you write, inserts them in one click and reports orphan pages. Persian-aware.

== Description ==

* Block editor sidebar with link suggestions, context and one-click insert.
* Classic editor / WooCommerce product metabox.
* Persian-aware matching across ي/ی, ك/ک, ZWNJ, diacritics and Persian digits.
* Phrases from per-post phrases, Yoast / Rank Math focus keywords and titles.
* Orphan / weak / most-linked report under Tools → Linkyar.
* WP-CLI: `wp linkyar rebuild`, `wp linkyar orphans`, `wp linkyar suggest <id>`.
